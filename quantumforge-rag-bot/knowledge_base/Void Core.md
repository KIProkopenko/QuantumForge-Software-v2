# Void Core

## Overview
The Void Core is a massive space station and superweapon capable of destroying entire planets. Built by the Dominion Authority, it represents the ultimate expression of Void Path technology and tyranny.

## Specifications
- Diameter: 160 kilometers
- Crew: 1.2 million personnel
- Weapon: Void Energy Beam powered by synthetic dark matter
- Defense: Heavy turbolasers, ion cannons, shield generators

## History
The Void Core was designed to enforce the Dominion Authority's rule through fear. Its first use was the destruction of Alderis Prime, a peaceful planet sympathetic to the Freedom Coalition.

## Weaknesses
Despite its power, the Void Core had a critical vulnerability: a small thermal exhaust port leading directly to the main reactor. This flaw was exploited by Freedom Coalition pilots during the Battle of the Void Core.

## Legacy
The destruction of the first Void Core became a turning point in the galactic civil war. A second, more powerful Void Core was later constructed but ultimately failed to prevent the Dominion's collapse.
