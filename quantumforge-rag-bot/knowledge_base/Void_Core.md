# Void Core

## Overview
The Void Core is a massive space station and superweapon capable of destroying entire planets. Built by the Dominion Authority.

## Specifications
- Diameter: 160 kilometers
- Crew: 1.2 million personnel
- Weapon: Void Energy Beam powered by synthetic dark matter

## History
The Void Core was designed to enforce the Dominion Authority's rule through fear. Its first use was the destruction of Alderis Prime.

## Weaknesses
Despite its power, the Void Core had a critical vulnerability: a small thermal exhaust port leading directly to the main reactor.
